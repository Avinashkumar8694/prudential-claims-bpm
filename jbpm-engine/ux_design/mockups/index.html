jBPM Engine — UX Design Mockups

A connected, click-through prototype — every sidenav item, tab, card, and node links to a real page in this set. Built with the app's real design tokens (app/src/styles.css) plus a small "modern polish" layer (gradients, icon chips, property-window modal — see shared.css). Rendered PNGs of every screen live in ../images/. Start at login.html and click through. See ../README.md for the full design doc set.
