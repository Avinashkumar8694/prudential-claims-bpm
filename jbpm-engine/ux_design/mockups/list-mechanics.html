List mechanics

Every list screen in this design is built from these three parts. They are specified once here and reused verbatim, so Instances, Tasks, Errors, Jobs, Audit, Deployments and Projects all filter, sort and column-pick identically.

Rule: the process instance id (PIID) is never optional. It is the identifier operators paste into a filter, quote in a ticket, and trace across Instances → Tasks → Errors → Jobs → Audit. It is pinned as the first column on every list where an instance is involved, rendered monospace, and click-to-copy. It cannot be hidden by the column picker.
